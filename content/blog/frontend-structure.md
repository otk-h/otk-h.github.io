# 如何构建高可读性的前端页面结构

构建页面时，我会优先关注**信息层次**，而不是先写样式。

## 1. 先把信息分组

- 头部导航
- 主要内容区域
- 辅助信息区域
- 页脚

当结构明确后，再拆分组件，能减少后续重构成本。

## 2. 样式命名保持语义化

尽量让类名表达用途，比如 `project-card`、`blog-list`，不要写和视觉强绑定的命名。

## 3. 先响应式，再细化动画

保证手机端可读，再增强桌面端交互体验。

```css
.container {
  width: min(1080px, 92%);
  margin: 0 auto;
}
```

> 可读性是后期维护效率的关键。
